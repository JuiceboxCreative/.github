# JuiceboxCreative defaults

Organisation-wide defaults for JuiceboxCreative repositories.

`pull_request_template.md` is the default pull request template.
GitHub uses it for any repository in the organisation that has no template of its own.
Loop fills the same sections on the pull requests its agents open, so people's pull requests and agent pull requests read the same way.

A repository keeps its own template by adding one at `.github/pull_request_template.md`.
